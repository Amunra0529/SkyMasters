2. REQUISITOS DEL CÓDIGO INICIAL:
- Los archivos de rutas (`/routes`) deben tener la estructura básica inicial exportando el router de Express (`express.Router()`).
- Los controllers (`/controllers`) deben incluir las funciones vacías (placeholders) comentadas con el nombre del integrante asignado.
- La vista principal `index.ejs` y las demás vistas de `/views` deben incluir las etiquetas de inclusión de EJS para el navbar y footer (`<%- include('partials/navbar') %>` y `<%- include('partials/footer') %>`).
- El archivo `app.js` debe dejar configurado el servidor Express, el motor de plantillas EJS, el middleware de archivos estáticos para `/public` y la importación de las rutas.
- Todo debe quedar listo para que cada desarrollador solo abra su archivo asignado y comience a codificar sin interferir con el resto.
